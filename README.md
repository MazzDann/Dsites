# Два сайти

Версія 1.0.0. Два самостійні сайти без збирання й залежностей: чистий HTML, CSS і JavaScript.

## Волосожар — `volosozhar/`

Живе небо над українськими містами.

- Небо в реальному часі для 26 міст, вершини Говерли або вашої геолокації: зорі з каталогу Hipparcos, планети, Місяць з фазою, Сонце, сутінки й день.
- Чумацький Шлях, атмосфера й сільський пейзаж на обрії (хата з вікнами, тополі, криничний журавель) малює WebGL-шейдер.
- Два вигляди: «Обрій» (роззиратися, тягнучи мишею чи пальцем) і «Усе небо» (купол, як на планісфері).
- Керування часом: смуга доби з сутінками, прискорення до години на секунду, режим «Сліди зір» — довга витримка, як на фото.
- Засвітка: від центру міста до темного неба — видно, скільки зір ховає міське світло.
- Пошук зір, планет, сузір'їв і туманностей; якщо об'єкт під обрієм, час перемотується до найближчої нагоди.
- Народне небо: Великий і Малий Віз, Волосожар, Косарі, Чумацький Шлях, Вечірня й Ранкова зоря — бурштиновим шаром на карті й окремим розділом.
- «Цієї ночі»: графік висоти Місяця й планет, таблиця сходу й заходу.
- Календар: метеорні потоки з оцінкою, чи заважатиме Місяць, фази Місяця, рівнодення й сонцестояння; можна додати подію в календар (.ics).
- «Нічний зір»: уся сторінка стає червоною, щоб не збивати темнову адаптацію очей.

Положення Сонця, Місяця й планет обчислюються в браузері (метод Пола Шлітера, прецесія IAU 1976). Зоряний каталог — стиснута копія даних проєкту [d3-celestial](https://github.com/ofrohn/d3-celestial) у `volosozhar/data/catalog.json` (285 КБ); якщо сторінку відкрито просто з диска, він підвантажується з jsDelivr.

## Мавка — `mavka/`

Концепт настільного синтезатора від вигаданої майстерні «Верба». Увесь звук синтезується наживо через Web Audio.

- Панель із 24 ручками й перемикачами: два генератори й шум, фільтр 24 дБ/окт, обвідна, рух (LFO), відлуння, реверберація «ліс», сатурація, одноголосий режим із ковзанням.
- Грати можна клавіатурою комп'ютера (`A`–`'`, чорні на `W E T Y U O P`, октава на `Z`/`X`), мишею, пальцями або MIDI-клавіатурою (Chrome, Edge).
- Осцилограф на екрані й заголовок «Мавка», літери якого реагують на частоти звуку.
- Вісім голосів — «Дійові особи» за «Лісовою піснею» Лесі Українки, кожен із демо-фразою.
- Живі схеми «Шляху звуку»: форма хвилі, частотна характеристика фільтра, обвідна, відлуння — змінюються разом із ручками.
- Секвенсор на 16 кроків у пентатоніці, випадкова мелодія, темп.
- Запис того, що граєте, у файл і посилання на налаштований звук, яке можна надіслати друзям.

## Як запустити

Потрібен Node.js 18 або новіший:

```bash
npm start
```

Відкрийте http://localhost:4321 — там стартова сторінка з обома сайтами.

Можна й просто відкрити `index.html` у браузері, але MIDI, геолокація й копіювання посилань надійніше працюють через `localhost`.

## Публікація на claude.ai

Опубліковані версії (приватні, доступ відкривається через «Поділитися» на сторінці):

- стартова сторінка: https://claude.ai/artifact/8WNbLrvBvRkJhAimtqhzib
- Волосожар: https://claude.ai/artifact/Xwee8vn882PPuZnxhiFNbn
- Мавка: https://claude.ai/artifact/1zpvV5kEFmgbdgUGDUxCcc

`npm run build:artifacts` збирає кожен сайт в один HTML-файл у `dist/` (стилі й скрипти вбудовано). На claude.ai сторінки не можуть відкривати геолокацію, MIDI й завантаження файлів, тому там приховано «Визначити моє місце», «Додати в календар», MIDI й посилання на звук; запис у Мавці зберігається через підтвердження claude.ai.

Каталог зір перезбирається так: скачайте `stars.6.json`, `starnames.json`, `constellations.json`, `constellations.lines.json`, `messier.json` з `https://cdn.jsdelivr.net/npm/d3-celestial@0.7.35/data/` в одну теку і запустіть `node scripts/prepare-catalog.mjs <тека>`.

## Структура

```
index.html          стартова сторінка
serve.mjs           статичний сервер без залежностей
scripts/            збірка для claude.ai і підготовка каталогу зір
volosozhar/
  js/astro.js       астрономія: Сонце, Місяць, планети, прецесія, схід і захід
  js/data.js        міста, сузір'я, назви зір, народне небо, метеорні потоки
  js/util.js        часові пояси, числа, відмінки
  js/sky.js         рендерер: WebGL-шейдер неба й 2D-шар зір
  js/app.js         головна сцена й керування
  js/sections.js    «Цієї ночі», «Народне небо», календар
  data/catalog.json каталог зір, сузір'їв і туманностей
mavka/
  js/engine.js      звуковий рушій на Web Audio
  js/presets.js     вісім голосів і підписи ручок
  js/ui.js          панель, екран, клавіатура, MIDI, запис
  js/page.js        шлях звуку, дійові особи, секвенсор, форма
```
